SISTEM PREDIKSI PENJUALAN - Irzi Atarr Denanta (29411007)

1. IDENTIFIKASI MASALAH UTAMA

UMKM kesulitan memperkirakan stok barang. Penentuan stok saat ini hanya berdasarkan intuisi sehingga sering terjadi overstock atau understock.

2. ANALISIS 5 WHYS

  • Kenapa stok sering salah? Karena UMKM tidak tahu estimasi penjualan.
  • Kenapa tidak tahu estimasi? Karena tidak ada pencatatan data dan analisis historis.
  • Kenapa tidak ada analisis? Karena proses bisnis masih dilakukan secara manual.

3. METODE ALGORITMA

Menggunakan Linear Regression untuk forecasting kebutuhan barang berdasarkan data historis penjualan harian/bulanan, dan pembobotan SAW untuk menentukan prioritas restock.
